# BlockBudds

BlockBudds is a Minecraft social site prototype. Share a build, like today's most-loved post, find streamers, and preview a profile. Posts, likes, and follows stay in the browser until a backend is hooked up.

## Open it locally

Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Hosting

This is a static site meant for Cloudflare Pages or Netlify at [blockbudds.com](https://blockbudds.com). `index.html` at the repo root is served at `/`.
